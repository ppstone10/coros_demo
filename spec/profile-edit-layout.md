# 三端个人资料编辑页布局规范

## 元数据

- Spec ID：`PROFILE-EDIT`
- 状态：已采纳
- 适用范围：Android Compose、iOS SwiftUI、HarmonyOS ArkUI 的个人资料编辑页

## 目标

- 三端个人资料编辑页的返回、标题和保存操作固定在页面顶部。
- 头像与资料字段位于独立的纵向滚动区域，内容不足一屏时仍从顶部开始排列。
- HarmonyOS 对齐 Android 与 iOS 已有的页面结构，消除短内容在滚动视口内整体垂直居中的大段空白。

## 非目标

- 不改变资料字段、校验、保存、头像选择或选择器行为。
- 不改变注册完成阶段的资料完善页结构。
- 不调整 Android、iOS 已符合本规范的视觉尺寸与间距。

## PROFILE-EDIT-001：固定编辑标题栏

个人资料编辑模式必须把返回、页面标题和保存操作放在资料滚动容器之外。滚动资料字段时，标题栏保持在页面顶部且不随内容移动。

三端实现边界：

- Android：固定标题 `Row` 位于带 `verticalScroll` 的资料 `Column` 之前。
- iOS：固定标题 `HStack` 位于 `ScrollView` 之前。
- HarmonyOS：编辑标题 `Row` 位于 `Scroll` 之前；`Scroll` 内只保留头像、资料字段、错误提示及底部内容间距。

## PROFILE-EDIT-002：短内容顶部起排

资料滚动区域中的内容必须沿主轴从顶部起排。内容不足滚动视口高度时，不得把整个资料块垂直居中，也不得使用固定负偏移补偿特定设备。

HarmonyOS 编辑模式的头像与第一行字段之间只允许使用明确的局部间距；不得通过让滚动内容占满并使用无尺寸 `Blank().layoutWeight(1)` 吸收剩余空间来间接定位。

## 验收与测试

- 执行 `./tools/check-profile-edit-layout.sh`，确认三端固定标题栏均位于各自滚动内容之前，且 HarmonyOS 编辑标题不再位于 `Scroll` 内。
- 执行 HarmonyOS 构建，确认 ArkTS 布局重构可编译。
- 人工运行：从“我”页进入“个人信息”，确认标题栏紧贴顶部安全区，头像和字段从标题栏下方开始，短内容不再上下居中；滚动字段时标题栏保持不动。
